# Contributing

Contributions are welcome.

This project is in an early design/prototype phase. Before making substantial firmware or architecture changes, please open an issue describing the use case and proposed approach.

## Principles

- Preserve MeshCore repeater reliability.
- Prefer low-power, broadly available hardware.
- Keep cloud interfaces independent of MeshCore internals.
- Do not commit credentials, private keys or deployment secrets.
- Document hardware assumptions and radio-region constraints.
- Keep radio configurations compliant with applicable local regulations.

## Changes

For non-trivial changes:

1. create or reference an issue;
2. use a focused branch;
3. update relevant documentation/ADR;
4. include test evidence where hardware or firmware behaviour changes;
5. submit a pull request with a concise rationale.

By contributing, you agree that your contributions are licensed under the project's Apache-2.0 license.
